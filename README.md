# 📊 Consolidador de Médias e Estatísticas Académicas

Projeto desenvolvido durante as aulas da disciplina de **Paradigmas de Linguagem de Programação (PLP)**.

## 📌 Sobre o Projeto
O script em Python simula a consolidação de notas e dados estatísticos de turmas universitárias. O sistema permite registar sequencialmente as médias de alunos distribuídos em quatro disciplinas, gerando ao final um relatório estruturado com métricas gerais e de participação.

## 🚀 Funcionalidades
- **Menu Interativo:** Seleção de disciplinas e introdução de notas.
- **Validação de Entradas:** Verificação de opções válidas para navegação no menu.
- **Relatório Estatístico:**
  - Total de alunos registados por matéria.
  - Média geral acumulada por disciplina (com tratamento de divisão por zero).
  - Identificação da disciplina com maior volume de lançamentos (adesão).

## 🛠️ Tecnologias e Conceitos Utilizados
- **Linguagem:** Python 3
- **Conceitos de PLP:** Estruturas de repetição (`while`), estruturas condicionais (`if/else`), listas/vetores, manipulação de índices e prevenção de exceções em tempo de execução.

## 📁 Estrutura do Código
- `main.py` (ou `script.py`): Ponto de entrada que gere a recolha contínua de dados, acúmulo de valores em vetores e a exibição do relatório final.
